# SalaryIQ – AI-Powered Employee Salary Prediction System

SalaryIQ is an intelligent salary prediction platform that combines Machine Learning and Google Gemini AI to help users estimate salaries, explore compensation insights, and receive personalized career guidance.

## 🚀 Project Overview

SalaryIQ provides separate salary prediction capabilities for the United States and India using independently trained Machine Learning models.

It also includes a Gemini-powered AI Assistant that answers salary-related questions, explains predictions, and provides career guidance.

## ✨ Key Features

- **Salary Prediction:** Predict salaries using trained Machine Learning models.
- **India Salary Prediction:** Estimate annual salaries in Indian Rupees (INR).
- **US Salary Prediction:** Estimate annual salaries in US Dollars (USD).
- **AI Assistant:** Integrated with Google Gemini for conversational assistance.
- **Dashboard:** View salary data and key statistics.
- **Analytics:** Explore salary trends and comparisons.
- **Bulk Prediction:** Upload CSV files for multiple salary predictions.
- **Model Insights:** Review model performance metrics.
- **Career Guidance:** Get advice about career development and salary negotiation.

## 🤖 Machine Learning Models

SalaryIQ uses separate models for India and the United States.

### United States

Input features:
- Department
- Job Title
- Experience
- Education Level
- Location

### India

Input features:
- Role Family
- Seniority
- Experience Band
- City

The models are trained independently because the datasets, currencies and feature structures differ.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/saitejareddy100/Employe-Salary-Prediction.git
```

### 2. Navigate to the project directory

```bash
cd Employe-Salary-Prediction
```

### 3. Create a virtual environment

Python 3.11 is recommended.

```bash
py -3.11 -m venv .venv
```

### 4. Activate the environment

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate
```

### 5. Install dependencies

```bash
python -m pip install --upgrade pip
```

```bash
python -m pip install streamlit==1.23.1 numpy==1.26.4 pandas==2.1.4 scipy==1.11.4 scikit-learn==1.3.2 pyarrow==14.0.2 plotly joblib google-genai python-dotenv
```

### 6. Configure Gemini API

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash
```

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey).

**Important:** Never upload your `.env` file or expose your API key publicly.

### 7. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
